# Repo Skills

This directory is for skills that help maintain this repository itself.

Repo skills are not part of the portable agent package and must not be installed by `scripts/install-playbook.sh` by default. The deployable runtime output stays in `dist/`.

Use repo skills for workflows that operate on this toolbox, such as turning new learnings or usage retros into updates for `principles/`, `planning/`, or `dist/`.

Planned repo skill:

- `skill-evolution` - process learning or retro input, decide whether it belongs in principles, backlog, an existing skill, or a new runtime skill.
